《人民日报》《新闻联播》每日内容获取方案
整理日期：2026-10-26
适用场景：个人学习、研究、每日摘要、资料归档
======================================================================

【先说结论】

1. 两家都没有公开、稳定、有文档的官方 API。
2. 新闻联播：央视网有每日页面和页面自用接口，可拿到标题、摘要、视频和全文。
   社区还有每天自动更新好的 Markdown 仓库，最省事。
3. 人民日报：只有官方电子版页面（HTML + 每版 PDF），没有公开 API。
   社区项目可以自动下载并合并 PDF。
4. 所有页面抓取方式都可能随官网改版失效，必须加缓存、重试和失败告警。
5. 人民日报电子版有版权声明：仅供阅读、学习研究，未经授权不得商用或镜像。

----------------------------------------------------------------------

仓库：
  https://github.com/DuckBurnIncense/xin-wen-lian-bo

特点：
  - GitHub Actions 每天自动抓取，定时为北京时间 20:30 左右。
  - 输出当天完整文字稿：新闻摘要 + 每条详细新闻 + 央视原文链接。
  - 2026-10 仍在正常更新。

当天文件 URL 规律：
  https://raw.githubusercontent.com/DuckBurnIncense/xin-wen-lian-bo/master/news/YYYYMMDD.md

示例（2026-10-25）：
  https://raw.githubusercontent.com/DuckBurnIncense/xin-wen-lian-bo/master/news/20261025.md

索引文件：
  https://raw.githubusercontent.com/DuckBurnIncense/xin-wen-lian-bo/master/README.md
  https://raw.githubusercontent.com/DuckBurnIncense/xin-wen-lian-bo/master/news/catalogue.json

优点：
  - 零代码，定时 curl 即可。
  - 已经是整理好的 Markdown，方便直接给大模型或知识库使用。

缺点：
  - 依赖第三方仓库，仓库停更或改名就失效。
  - 建议保留方案 2 作为回退。

方案 2：自己抓央视网官方页面（推荐作为主方案或回退）
----------------------------------------------------------------------

每日索引页：
  https://tv.cctv.com/lm/xwlb/day/YYYYMMDD.shtml

示例：
  https://tv.cctv.com/lm/xwlb/day/20261025.shtml

页面结构：
  - 页面里有当天所有新闻的链接。
  - 去重后，第一个链接是“本期节目主要内容”摘要页。
  - 其余链接是当天每条新闻的独立页面。

单条新闻页提取规则：
  - 标题：CSS 选择器  .playingVideo .tit
  - 正文：CSS 选择器  #content_area
  - 标题里可能带 “[视频]” 前缀，需要去掉。

处理流程：
  1. GET 每日索引页。
  2. 提取所有 https://tv.cctv.com/YYYY/MM/DD/VIDE*.shtml 链接并去重。
  3. 第一个链接作为摘要页。
  4. 其余链接逐条 GET，提取标题和 #content_area 正文。
  5. 按顺序拼接，输出 Markdown 或纯文本。

优点：
  - 直接来自央视网，不依赖第三方仓库。
  - 能拿到每条新闻的完整正文。

缺点：
  - 页面结构改版后选择器会失效。
  - 需要控制请求频率，不要并发猛拉。

方案 3：央视栏目接口（标题、摘要、视频，不是全文）
----------------------------------------------------------------------

接口地址：
  https://api.cntv.cn/NewVideo/getVideoListByColumn?id=TOPC1451528971114112&n=20&sort=desc&p=1&mode=0&serviceId=tvcctv

说明：
  - TOPC1451528971114112 是《新闻联播》栏目 ID。
  - 返回字段包括：title、time、brief、url、guid 等。
  - brief 是“本期节目主要内容”的条目列表，不是完整文字稿。
  - 这是央视页面自用接口，没有公开文档，可能变更。
  - 海外网络环境可能不稳定。
  - 已验证 2026-10-25 当天数据可正常返回。

适合用途：
  - 快速判断“今天新闻联播播了什么”。
  - 获取当天视频链接和标题清单。
  - 不适合直接当全文源。

方案 1：官方电子版页面（唯一稳定的官方内容源）
----------------------------------------------------------------------

当天版面首页：
  https://paper.people.com.cn/rmrb/pc/layout/YYYYMM/DD/node_01.html

示例：
  https://paper.people.com.cn/rmrb/pc/layout/202610/26/node_01.html

页面结构：
  - node_01.html 到 node_N.html，每天版数不同。
  - 每个版面页里有当天该版的文章链接。
  - 文章链接规律：
      .../content/YYYYMM/DD/content_*.html
  - 每个版面还有一个 PDF：
      .../attachement/YYYYMM/DD/<uuid>.pdf
  - PDF 的 uuid 每天不同，必须从页面解析，不能直接拼接。

文章页提取规则：
  - 正文：CSS 选择器  #ozoom
  - 兼容旧选择器：#rwb_zw、.rm_txt_con、.show_text
  - 标题：<h1> 标签

处理流程（文字版）：
  1. GET node_01.html。
  2. 从页面导航或链接中解析出 node_01 到 node_N。
  3. 逐版 GET，收集文章链接并去重。
  4. 逐篇 GET 文章页，提取 <h1> 和 #ozoom。
  5. 按版面顺序输出 Markdown。

处理流程（PDF 版）：
  1. 同上解析每个版面的 PDF 链接。
  2. 下载所有版面 PDF。
  3. 用 pypdf / PyPDF2 合并成一个完整 PDF。

优点：
  - 官方内容源，权威、稳定。
  - 同时有文字和 PDF。

缺点：
  - 没有公开 API。
  - 版面数量、HTML 结构、PDF 地址规则可能改版。
  - 版权限制：仅供个人阅读、学习研究，禁止商用和镜像。

五、推荐落地方案
======================================================================

【新闻联播】

每天 20:45：
  1. 先拉 DuckBurnIncense 的当天 Markdown：
     https://raw.githubusercontent.com/DuckBurnIncense/xin-wen-lian-bo/master/news/YYYYMMDD.md
  2. 如果 404 或内容为空，回退到央视日页：
     https://tv.cctv.com/lm/xwlb/day/YYYYMMDD.shtml
  3. 解析 #content_area，自己拼全文。

每天 21:30：
  - 再重试一次，防止当天更新延迟。

【人民日报】

每天 07:30：
  1. 用 AnzhiZhang/PeoplesDaily 的 Docker 镜像跑一次，产出合并 PDF。
  2. 如果要文字版，解析 node_*.html 里的文章链接，再取 #ozoom。
  3. 保存到按日期命名的目录。

每天 09:00：
  - 重试一次，防止早上版面未出全。

【通用要求】

  - 按日期缓存，避免重复抓取。
  - 每次请求加 User-Agent。
  - 串行或低并发，建议间隔 1–2 秒。
  - 失败重试 2–3 次，指数退避。
  - 记录日志：日期、来源、条数、失败原因。
  - 连续失败时发通知（邮件、Server 酱、钉钉、企业微信等）。
  - 不要绕过验证码、登录或付费墙。

2. 央视 api.cntv.cn 是页面自用接口，不是正式开放 API。
3. 人民日报电子版版权声明：
   内容仅供阅读、学习研究使用；未经授权，不得用于商业目的，
   不得转载、复制、发行或镜像。
4. 个人做每日摘要、研究分析通常没问题；商用请走授权。
5. 控制抓取频率，遵守 robots.txt 和网站条款。
6. 不建议把抓取内容公开再分发或做成镜像站。
7. 第三方 GitHub 仓库可能随时停更，生产环境要有回退方案。

八、方案选择建议（一句话版）
======================================================================

  - 只想每天拿到新闻联播全文：
      用 DuckBurnIncense 的 raw Markdown。

  - 想稳定、可控、不依赖第三方：
      自己抓 tv.cctv.com 的 day 页面 + #content_area。

  - 只想每天拿到人民日报 PDF：
      用 AnzhiZhang/PeoplesDaily 的 Docker 镜像。

  - 想要人民日报文字版：
      解析 paper.people.com.cn 的 node 页面和 #ozoom。

  - 想要零代码订阅：
      新闻联播用 RSSHub /cctv/lm/xwlb；
      人民日报没有现成 RSS 全文方案，需要自己抓。

  - 需要商业 SLA 或授权：
      走万象数据、人民网图文数据库等商业/机构渠道。
