# 中国官方新闻解读

把《新闻联播》《人民日报》的本地稿件还原为**可比、可核验、可回验**的政策信号。既分析出现了什么，也审查没有出现什么；既读正文，也读**结构**（条目顺序、版面、文体等级）。

材料已在本地，本 skill **不负责取数**。所有结论只能来自用户提供的稿件，以及用户明确许可的本地语料库。

## 一、输入与预处理

1. **确认材料边界**：只处理用户给出的目录或文件。缺原文时输出 `无法取证`，不补外部信息，不凭记忆还原通稿措辞。
2. **识别媒体**：新闻联播 / 人民日报 / 其他。两家的信号结构不同，见 `references/media-grammar.md`。
3. **识别口径来源（必做）**：稿件是自采、还是"据新华社""新华社北京X月X日电"。这决定它是独立信源还是转述。
4. **识别文种**：联播是时政通稿/本台评论/国内联播快讯/国际新闻；人民日报是社论/本报评论员/任仲平/钟声/要闻/理论版/记者报道。
5. **归档**：材料按 `媒体_日期_文种` 命名入库，后续差分依赖这个索引。用 `scripts/corpus.py scan <目录>` 生成。

## 二、强制边界

1. 每条结论必须挂 `事实`／`多源证实`／`单源待核`／`文字信号`／`推断`／`情景`／`存在冲突`／`无法取证` 之一。
2. **同源陷阱**：《新闻联播》和《人民日报》同载一篇新华社通稿，是**一个**信源，不是两个。两家各自改写才算两个。不得用转发叠加置信度。
3. 先确认可比性（同层级、同文种、同议题、原文完整）再做词语比较。跨文种的词频、缺位率、强弱不得直接计算。
4. 不把单次缺词、段落缩短、同义替换直接解释为政策降级。必须过缺位审查的闸门。
5. 不用单一总分表示政策力度。分别报告方向、紧迫度、工具具体度、资源承诺度、执行成熟度、证据覆盖率。
6. **排序与版面只在同类结构可比时解释**。联播的"时政→国内→国际"是固定栏目结构，跨栏目比较顺序无意义；只比较栏目内排序。
7. 讲话不等于资源配置，政策发布不等于执行，项目开工不等于经营兑现，报道篇幅不等于政策权重。
8. 不从单条新闻推断人事变动、股市方向或具体落地时间表。

## 三、工作流

1. **建立基线**：用 `scripts/corpus.py baseline <目录> --topic <议题>` 找出上次同类稿件、去年同期稿件、历史必现样本。基线不足时，明确降级为"无基线，仅作单篇解读"。
2. **抽结构信号**：条目数、栏目内排序、时长（若稿中有）、人民日报版面与文体等级。跑 `scripts/corpus.py structure <文件>`。
3. **抽语义单元**：按 `主体+动作+程度+对象+工具+执行者+资源+时间+结果+约束` 切分（见 `references/policy-language-grammar.md`），只比较完整槽位。
4. **逐句差分**：`scripts/corpus.py diff <旧> <新>`。原文差异与政策解释**分栏输出**，禁止把 diff 结果当结论。
5. **缺位审查**：四道闸门，见 `references/absence-analysis.md`。状态只能用文件里给定的那五档措辞。
6. **受控联想**：见下节。每个联想必须写桥梁与证伪信号。
7. **兑现跟踪**：按 `表态 → 重复表态 → 正式文件 → 实施细则 → 预算/额度 → 资金下达 → 审批/招标/执法 → 主体行为 → 结果` 定位当前处在哪一级。
8. **输出**：严格套 `references/output-template.md`。

## 四、受控联想（本 skill 的推理层）

"联想推理"只能沿三条**可验证的边**展开：

| 边 | 允许的推法 | 必须给出 |
|---|---|---|
| 时间边 | 与去年同期、上次同级报道、连续N次出现的关系 | 基线文件与出现率 |
| 机构边 | 发文/参会/表态主体的上下游链条（会议→部委→地方→执行主体） | 主体链条的原文依据 |
| 工具边 | 表态→文件→预算→项目→执法→结果的兑现位置 | 当前所处层级与下一级证明信号 |

每条联想必须写成三段：**观察 → 桥梁 → 待验证**。缺桥梁的一律降为"猜测"，不得进入结论区。

**禁止**：把巧合时间点写成因果；把外媒转述当原文；把"未提及"直接写成"取消"；从单篇稿件推人事与市场结论；为凑结论引用未提供的材料。

推理强度自检：如果一个联想无法写出**证伪信号**（什么情况出现就说明我错了），它就不是推理，是叙事。

## 五、两类材料的读法差异

**新闻联播**：正文高度模板化，信息密度低但**冗余度稳定**——正因如此，任何偏离模板的地方都是信号（措辞升级、新增限定语、排序前移、配发本台评论、时长异常）。别被"会议强调"的重复麻痹，要找的是**这一次和上一次不一样的那一处**。

**人民日报**：信号分布在**版面 + 文体 + 标题**三层。头版头条、评论版、理论版的权重完全不同；社论/任仲平/本报评论员/钟声代表不同的发声层级。标题的动宾结构变化往往比正文更早反映定调变化。细则见 `references/media-grammar.md`。

## 六、工具

```
python scripts/corpus.py scan      <目录>            # 建索引：日期/媒体/文种/字数/口径
python scripts/corpus.py baseline  <目录> --topic 关键词
python scripts/corpus.py terms     <目录> --topic 关键词   # 历史出现率
python scripts/corpus.py structure <文件>
python scripts/corpus.py diff      <旧文件> <新文件>
```

零依赖，Python 3.9+，UTF-8/GBK 自动识别。脚本只做机械抽取，**判断一律由模型完成**——不要因为脚本输出了"新增"就当作政策新增。
