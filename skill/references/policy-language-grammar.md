# 政策语言语法

官方文本是高度受限的语言。用"感觉语气变强了"做判断不可靠；可靠的是一条完整的语义单元在相邻两版文本里的槽位变化。

## 一、语义槽位

每个政策语义单元拆成十槽：

`主体 + 动作 + 程度 + 对象 + 工具 + 执行者 + 资源 + 时间 + 结果 + 约束`

例：

> 国家发展改革委**加快**推动**新型基础设施建设**，**通过专项债**支持**地方**在**今年底前**形成**实物工作量**，**严禁**搞重复建设。

- 主体：国家发展改革委
- 动作 + 程度：加快推动
- 对象：新型基础设施建设
- 工具：专项债
- 执行者：地方
- 时间：今年底前
- 结果：形成实物工作量
- 约束：严禁重复建设

**只比较完整槽位。** 单个关键词的变化不足以推力度变化——"推动"变"加快"是真的升级，但"加快推动"在对象从"试点"变成"全面"时，才是实质变化。

## 二、动作阶段（判断处在哪一步）

| 阶段 | 常见表达 | 能证明什么 |
|---:|---|---|
| 1 | 关注、研究、探索、跟踪 | 进入议程 |
| 2 | 谋划、储备、完善、酝酿 | 准备政策或能力 |
| 3 | 推动、促进、引导、支持 | 方向性部署 |
| 4 | 加快、加力、深入、纵深、更大力度 | 紧迫度或力度提升 |
| 5 | 出台、实施、落实、印发、部署 | 已进入执行框架 |
| 6 | 确保、全面实施、坚决、严禁、不得 | 强结果或强约束 |
| 7 | 拨款、发行、下达、审批、开工、采购、处罚 | 已配置资源或已行动 |

**阶段跃迁是最硬的文字信号**：从 3 跳到 5（"推动"→"实施"）比从 3 跳到 4 强得多。反过来，从 5 退回 3 是重要信号，但也可能是议题换文种（从会议通稿转为部委文件）所致，须先过可比性。

同一词强度随对象、层级、文种变化。"加快"出现在政治局会议通稿与出现在部委通知里，含义不同。

## 三、修饰语的准确含义

| 修饰语 | 含义 | 常见误读 |
|---|---|---|
| 持续 | 延续既有动作 | 误读为加码 |
| 适时 | 条件触发，未定时间 | 误读为即将 |
| 及时 | 现实需要提高，仍可能在准备阶段 | 误读为已启动 |
| 加快 | 速度要求提高 | — |
| 加力 | 力度提高，但资源规模未知 | 误读为已增投入 |
| 深入 / 纵深 | 从启动转向持续治理 | 误读为新政策 |
| 常态化 | 从专项行动转为稳定机制 | 误读为力度下降 |
| 稳妥 / 有序 | 控制节奏与副作用 | **误读为弱支持**（实为约束加强） |
| 精准 / 务实管用 | 强调效率与传导 | 可能暗示既有政策效果不足（属推断） |
| 坚决 / 全面 / 严禁 | 强约束 | — |

## 四、约束词是独立的信号轴

约束词（严禁、不得、坚决遏制、防止、守住底线、不搞一刀切）与支持词走**两条独立的轴**。

- 支持加强 + 约束加强 = 扩张但划边界，常见于产业政策
- 支持不变 + 约束消失 = 边界放宽，往往是重要但易漏的信号
- 支持加强 + 约束消失 = 强扩张

**反向缺位同样要审**：某行业仍被支持，但"严控新增产能"一类约束消失，可能意味着政策边界变化。须核查专项文件是否保留约束后才能下结论。

## 五、会议通稿的三段式

`形势评价 → 总体要求 → 部署与执行`

解读顺序：

1. 形势评价里的判断词（"稳中向好""压力加大""不确定性上升"）→ 定调
2. 总体要求里的定调词组（"稳中求进""以进促稳""先立后破"）→ 方法论
3. 部署段的任务条目数、排序、是否点名 → 优先级

**条目数变化**：新增任务条目通常是扩容；条目合并通常是聚焦；条目消失须过缺位闸门。

## 六、不得使用的推法

- 由单个词的出现/消失直接推力度
- 由形容词密度推重要性
- 由篇幅长度推政策权重（联播时长另有栏目因素）
- 把"罕见表述"直接当"重大转向"，除非能给出上一次出现的时间
- 把外媒或自媒体的解读当作官方口径的一部分
