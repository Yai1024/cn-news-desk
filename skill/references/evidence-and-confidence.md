# 证据、兑现与置信度

## 一、八类标签（每条结论必挂其一）

| 标签 | 含义 |
|---|---|
| `事实` | 提供的原文直接支持，无需推断 |
| `多源证实` | 至少两个**独立**可靠来源支持 |
| `单源待核` | 一个可靠来源，缺独立旁证 |
| `文字信号` | 文本中确实出现的方向或措辞，强度待兑现 |
| `推断` | 由事实与文字信号推出，必须写桥梁 |
| `情景` | 未来路径假设，不是预测事实 |
| `存在冲突` | 来源、数字、行为相互矛盾 |
| `无法取证` | 关键原文/数据/基线不可得 |

## 二、同源陷阱（本 skill 最强调的一条）

《新闻联播》和《人民日报》刊播同一篇新华社通稿时：

- **是一个信源，不是一个以上。**
- 只能标 `单源待核`，不能标 `多源证实`。
- 联播的"选播"行为本身可作单独信号（选播=重视），但内容仍属新华社口径。

判定方法：看稿件有无"据新华社""新华社X月X日电""新华社记者"字样，以及两家正文是否高度一致（可用 `corpus.py diff` 快速比对，相似度 > 0.9 即判同源）。

真正的 `多源证实` 需要：不同采写主体、不同发布渠道、可独立核验的内容。例如：联播报道 + 人民日报本报评论员文章 + 部委官网原文，三者互不隶属同一条通稿。

## 三、本地材料的来源层级

1. 用户提供的一手稿件（联播完整文字稿、人民日报原版面文字）
2. 用户提供的同源转载（同一通稿另一处刊发）
3. 用户提供的节选、摘要、截图转录
4. 用户口述、记忆中的表述

**层级 3、4 只能作线索，不得单独支撑结论**；引用时明确标注来源层级。

## 四、兑现阶梯（判断政策走到哪一步）

```
表态 → 重复表态 → 正式文件 → 实施细则 → 预算/额度
     → 资金下达 → 审批/招标/执法 → 主体行为 → 经营/社会结果
```

- 在本地材料里给每条政策信号定位到具体阶。
- 常见错位：把"重复表态"当"已实施"；把"项目开工"当"经营兑现"。
- 每一阶都应有可核验的载体。载体不在材料里 → 标 `无法取证`，不要默认完成。

## 五、六个独立维度（不合成总分）

| 维度 | 问什么 |
|---|---|
| 方向 | 扩张、收缩、治理、托底，哪一个是明确的 |
| 紧迫度 | 有无时间要求（"今年底前""适时"差别很大） |
| 工具具体度 | 是否有可执行工具（专项债、试点、标准、考核） |
| 资源承诺度 | 有无金额、额度、人员、项目 |
| 执行成熟度 | 处在兑现阶梯哪一级 |
| 证据覆盖率 | 这六维里有多少是靠本地材料能支撑的 |

**不产出"政策力度 7.5/10"这种分数。** 各维度不同向是常态，一个分数会掩盖方向。

## 六、自我校验（输出前必做）

1. 每条 `推断` 是否写了桥梁？没写 → 降为猜测或删除。
2. 每条 `推断` 是否写了证伪信号？没有 → 不是推理。
3. 是否有把同一通稿两次刊发算成多源？有 → 改为 `单源待核`。
4. 是否有把"未提及"写成"取消"？有 → 退回缺位闸门。
5. 六维是否被偷偷合成了总分？有 → 拆开。
6. 结论区里是否混入了材料之外的记忆内容？有 → 删除或标 `无法取证`。
