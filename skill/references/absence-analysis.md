# 缺位分析

"这次没提"是本领域最容易被滥用的信号。四项闸门全过，才能谈缺位。

## 闸门一：可比性

同层级、同文种、同周期、同议题、原文完整。任一不满足即停止，降为背景参照。

本地材料常见不可比：拿会议通稿比部委通知、拿头版社论比内页报道、拿 3 分钟长条比快讯。这些都不算出缺位，算出"文种不同"。

## 闸门二：历史必现率

`历史出现率 = 含该议题的可比文本数 / 合格可比文本总数`

用本地语料库计算：

```
python scripts/corpus.py terms <目录> --topic 关键词
```

判读：

| 出现率 | 含义 |
|---|---|
| < 40% | 单次缺失通常无解释力 |
| 40%—60% | 普通差异 |
| 60%—80% | 高敏感，需继续核 |
| > 80% | 异常缺位候选，进入闸门三 |

**合格语料少于 5 篇时，不得计算出现率**，直接标注"基线不足"。

## 闸门三：同义吸收与位置迁移

逐项排除：

1. 同义词、上位词、拆分表达（"乡村振兴"融入"三农工作"整体表述）
2. 挪到另一段落或另一条目
3. 转移到别的载体（会议不提、部委文件提；联播不提、人民日报评论提）
4. 季节性/会议主题差异（年底会议谈次年任务，年中会议谈执行）
5. 阶段任务已完成（"脱贫攻坚"消失属正常，不是降级）

## 闸门四：资源与行动

查同期是否有预算、债券、信贷、项目、招标、采购、执法、人员、结果的同步下降。

**只有文字与资源行动同时下降，才能写"投入下降证据较强"。**

## 结论等级（只能用这五档措辞）

| 状态 | 允许的表达 |
|---|---|
| 仅本次缺失 | 本次未出现，无方向结论 |
| 历史高频但有同义/位置替代 | 表述迁移，不构成降级 |
| 历史高频、连续缺失 | 高敏感缺位待核 |
| 连续缺失且排序/版面同步下降 | 优先级可能下降 |
| 文字 + 资源 + 行动同步下降 | 投入下降证据较强 |

不允许出现"取消""放弃""叫停"这类定性，除非另有原文直接支持。

## 反向缺位

同时检查**本该出现的约束是否消失**：支持性表述仍在，但"严禁""防止""守住底线"不见了。这可能是边界放宽，也可能是约束移到了专项文件。须核查后表态。

## 采集保护（本地材料版）

以下属于**材料状态**，不是官方信号，一律输出 `无法取证`：

- 文件缺失、只截了半篇、正文被删节
- 只有标题没有正文
- 稿件非当日完整版（联播文字稿常有条目删节）
- 目录里某天没有文件

**不要因为自己手上没有，就说官方没报道。**
