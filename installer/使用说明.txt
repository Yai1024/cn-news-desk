政策解读台 使用说明
==================

一、首次使用
1. 双击桌面上的「政策解读台」。
2. 点「获取新闻稿」，等待抓取完成（首次约 15～20 分钟）。
3. 点「开始解读」，结果会逐字显示在下方。

二、API 密钥
安装时填写的密钥保存在安装目录的 agent.ini 中，只在本机使用。
需要更换密钥时：开始菜单 → 政策解读台 → 修改 API 密钥，
把 api_key= 后面改成新密钥，保存即可。

密钥获取：https://platform.deepseek.com/api_keys
未填写密钥时，「开始解读」只会提示，不会发送请求。

三、文件位置
output\     抓取的新闻稿和解读结果
agent.ini   API 与材料窗口配置
skill\      解读方法论

四、卸载
开始菜单 → 政策解读台 → 卸载政策解读台。
卸载默认保留 output\ 稿件和 agent.ini；如需全部删除，在卸载窗口选择
「卸载并删除全部数据」。

五、常见问题
- 抓取失败：看 output\logs\ 下的日志；网站改版可能导致选择器失效。
- 解读报 401：密钥无效或已删除。
- 解读报 402：账户余额不足。
- 网络错误 12152：程序会自动重试；仍失败时可在 agent.ini 配置代理。
